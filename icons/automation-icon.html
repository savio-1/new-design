Cogentiq · Gradient icon set · Reference 01

Automation, in the Indigo aura

The flow glyph from the Cogentiq icon library, redrawn flat and set on a rounded square that carries the gradient. The tile is self-lit, so the same asset sits on a cream page and a deep ink page without a mode-specific variant.

Light mode
Dark mode

Size ramp

One vector, scaled. The blur radius scales with the tile, so the aura keeps its proportions from a 24 px list icon to a 96 px feature tile.

Recipe

Every colour is a Cogentiq token. The gradient is built from soft blooms rather than a single linear ramp, which is what gives the reference shapes their depth.

Tile
96 × 96 grid, corner radius 26 (27%). Diagonal ground from Midnight Violet to Deep Ink, then four blurred discs clipped to the tile. Gaussian blur, standard deviation 13.
Glyph
The Figma outline icon converted to flat fills: four solid nodes at radius 2.1, connectors at stroke 1.8 with round caps. Scaled 2.4× to occupy the centre 48 px of the tile.
Edge
A 1 px white hairline at 16% opacity keeps the tile from dissolving into a dark page without reading as a border on a light one.
Modes
No theme switch inside the asset. The tile is always dark with a light glyph, so it holds its contrast on either ground. Only the page around it changes.
