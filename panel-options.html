Context Studio in the platform panel

Four ways to show it, side by side — same panel, same content, only the treatment of the Context Studio row changes. Each is shown opened (240px) and crunched (68px), which is the state the panel is in by default. Off-plan throughout, so the Try pill and the dot are visible.

What would help: which one reads as “this is a thing you can buy” fastest, which one you would still find on the fifth visit, and whether the crunched state carries any of it. The row is the only thing that differs — everything else is held constant on purpose.

Below the categories

Past the last category, under a rule. The rule is what says it is not one of them; the row stays last wherever the list ends.

D

Boxed, with a line

Same place as B, but a box and one line of copy do the separating instead of a rule — the only option that says what it is without a hover.

Panel footer

The same row dropped to the foot of the panel. Furthest from the categories, and in one fixed place however many of them are open.
