Getting started

Link the stylesheet and add class="cq" to the body. Dark is the product default; set data-mode="light" on the root element to switch. Every component below is written against tokens only, so both themes come free — never hard-code a colour in a screen.

Token names match Figma. A variable renamed in the Figma library maps to exactly one line in the stylesheet, so the two stay in step without a translation table.

Colour

Every themed token, with both values. The chip shows the value live in whichever theme the page is in; the pair beside it shows dark and light, with the inactive one dimmed.

Typography

Geist for the interface, Geist Mono for identifiers and machine values — model ids, token names, API keys. Use the ramp classes rather than setting sizes ad hoc.

Radius & elevation

Four radii and seven shadows carry the whole product. Shadows are tokens because they carry different alpha per theme: what reads on near-black is too heavy on white.

Buttons

Figma strokes sit inside the box, so every bordered control carries an explicit height — without it a 1px border grows the control 2px past its designed size.

Form fields

A label and a control make a field. The control is a flex box, so icons and buttons sit inside it rather than beside it.

Filters

A dropdown button with an optional count, and the popover it opens. Rows come in two kinds: a checkbox for multi-select, a tick for single-select.

Tags, badges & pills

Five semantic tones set with data-tone. A tag stays grey until its parent is hovered or selected; a badge carries its colour always. Use a badge wherever the tone must read without an interaction.

Cards & tables

The two ways the product lists things. Both tint their tags on hover, so a row and a card behave identically for the same content.

Navigation & segments

Sidebar items, rail buttons, and the three segmented controls: text tabs, numbered steps, and the icon toggle used for view switching.

Surfaces & overlays

Modal shell, side panel and the key/value row that fills them. The panel here is pinned open inside a frame; in a screen it slides in from the right edge.

Tiq

The assistant surface. Its rotating conic stroke is the one place the system uses a fixed brand gradient rather than a token — it is deliberately identical in both themes, so Tiq reads as the same thing wherever it appears.
