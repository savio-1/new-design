Widths
--rail-w: 68px and --rail-w-open: 240px. Padding is 8px 16px at both, so content is 36px or 208px.
One rule, two positions
Every row is justify-content: center with 8px padding. That puts the icon at x=10 in a 36px box and at x=8 once a label flexes beside it — the two positions the component specifies, without a width-conditional rule.
Item
36px tall, 16px icon, 8px gap, radius 8.
Group header
24px tall, 24px gradient tile, 6px gap, 16px chevron.
The divider
Zero height, stroke drawn above it. A 1px box adds a row and pushes everything below out of rhythm.
Active item
tonal-1 fill, card/selected border, coloured-blue label at 500. Padding drops to 7px so the border does not push the icon off the 8px line — Figma strokes sit inside the box.

Rules

Each of these was a decision with a reason. Change them deliberately, not by accident.

Opens on hover
120ms in, 220ms out. The asymmetry stops a cursor crossing the panel from flashing it open, and stops an overshoot on the way back from shutting it. Focus opens it too — a panel reachable only by hover is not reachable by keyboard.
Overlays, never pushes
The panel is fixed and the shell holds a constant 68px gutter, so opening lays it over the page. A hover is not worth relaying out a page for, and content that shifts under the cursor is content you then have to find again.
One category open
Opening an item or a header collapses the rest, and the panel starts on the section holding the active item. Crunched this matters more, not less: the icons carry no grouping of their own, so every expanded category runs into the next.
Expansion outlives the width
Which category is open is independent of crunched/opened, so peeking and leaving never loses your place.
Empty groups are labels
A group with nothing under it keeps its chevron but does not toggle. No dead disclosures.
Offerings sold separately
Their own top-level row, never a slot inside another category — a top-level row is the only one the one-open rule can never hide. Off-plan it still shows, with a pill when opened and a dot on the tile when crunched.
Never grey out an upsell
The tile keeps full colour. Greying it reads "not for you", which is the opposite of the job.
Highlight where it will be seen
The panel is crunched by default, so any emphasis living in the label row is emphasis almost nobody sees. The dot is on the tile for that reason.
Motion is periodic, not constant
The pill's sheen crosses once every 3.4s with a long hold. Continuous motion in a nav panel nags. Reduced motion drops it.
Preview on a dwell
300ms to open, 240ms to close. Nobody clicks a thing they have not been sold; the offer should arrive while the eye is already on the row. The close is slow enough to cross into the preview and reach its buttons, and the panel is held open while it is up.

The preview clip

What plays inside the offer, at full size. Unlike the panel above, this is not built from this page's tokens — it is a separate, already-published piece (Cogentiq Context Intro), embedded whole rather than rebuilt component by component. That trade is explicit: it reads as finished in a way a token-driven build does not, and it can drift from this page, because it is not made of this page's parts.

Scatter
Around twenty app icons and UI fragments drift in across three blurred depth planes — the enterprise data a company already has, spread across tools with nothing connecting them.
Merge
Everything converges toward a single point off to the right as the camera pans there, and the sphere — the context layer — forms and powers up from what merged into it.
Chips
Six labelled chips (Glossary, Ontology, Data binding, Tool binding, Prompts, Policies) orbit the sphere and spiral into it — the categories, named this time rather than left as anonymous icons.
Reveal
The sphere blooms into a full-frame flash, the ground cuts from night to a light sky, and the piece closes on a lockup: Cogentiq Context — The Enterprise AI Context Layer.
How it is mounted
An <iframe srcdoc>, not an <img> or a linked page: the clip's markup, CSS and script travel inside this document as one JS string, so nothing extra loads at view time and nothing is fetched cross-origin. The same string mounts all three places it appears: this stage, the box in the offer, and the big view the offer's expand button opens.
Controls
Pause/Play stop and resume every animation in the embedded document via Animation.pause()/.play(); Replay cancels and restarts them, the same call the clip's own bottom-right replay button makes. There is no scrub bar here — the clip does not expose a single timeline the way the retired build's GSAP timeline did, only however many independent CSS animations happen to be running.
Reduced motion
Handled inside the embedded document itself, which collapses every animation to its end state under prefers-reduced-motion: reduce — not something this page adds on top.

Open questions

Decisions I made without a source, or left alone on purpose. Settle these first — they are the things most likely to change what you build.

Context, twice
Library still carries its own Context item from the Figma spec, alongside the new top-level Context Studio. If Context Studio replaces it, the Library row should go.
Re-opening when crunched
The crunched variant draws no control of its own. Hovering the panel is currently the whole affordance. There is no pin, so the panel cannot be held open.
The Context Studio glyph
Drawn to the sprite's 16px, 1.5-stroke language. The design system file has no Context Studio component, so this is not an export. Replace it when one exists.
Marketplace wash in dark
Figma names the pill's fill Gradient/blue but returns no value. Light is sampled from the component render; dark is derived. Replace if a dark variant gets drawn.
Groups with no children
Evaluate, Monitor and Resources are collapsed headers in every Figma variant. Their contents have not been designed.
Entitlement is a stub
A constant read off ?cs=owned. There is no real plan model, and only Context Studio is sold separately.
