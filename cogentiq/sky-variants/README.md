# Hero sky candidates

Eight ramps for the homepage gradient, generated by `gen-variants.py` from the
design-system rungs in `../index.html`. Everything but the ramp — saturation,
bloom, falloff — is identical across all eight, so the comparison is only ever
about colour.

Side-by-side: <https://claude.ai/code/artifact/9a99db46-a765-4924-84b9-20e8bbc5a166>

Regenerate after any change to the ramps:

    python3 gen-variants.py

Once one is picked, its stops go into the `--sky-*` tokens in `../index.html`
and this folder can go.
