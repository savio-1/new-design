Every row is justify-content: center with 8px padding. That puts the icon at x=10 in a 36px box and at x=8 once a label flexes beside it — the two positions the component specifies, without a width-conditional rule.

In B and C, the same .rail-rule the Marketplace uses, carried inside the group so it travels with the row: 16px under the last category, 12px over Context Studio. A and D have nothing to separate and hide it.
The Context Studio box
D only, and opened only — crunched, the box has no copy to hold and a card around a lone tile reads as a dead button, so at 68px the row is a plain tile like every other category. What is in it

Rules

Each of these was a decision with a reason. Change them deliberately, not by accident.

Opens on hover
120ms in, 220ms out. The asymmetry stops a cursor crossing the panel from flashing it open, and stops an overshoot on the way back from shutting it. Focus opens it too — a panel reachable only by hover is not reachable by keyboard.
Overlays, never pushes
The panel is fixed and the shell holds a constant 68px gutter, so opening lays it over the page. A hover is not worth relaying out a page for, and content that shifts under the cursor is content you then have to find again.
One category open
Opening an item or a header collapses the rest, and the panel starts on the section holding the active item. Crunched this matters more, not less: the icons carry no grouping of their own, so every expanded category runs into the next.
Expansion outlives the width
Which category is open is independent of crunched/opened, so peeking and leaving never loses your place.
Empty groups are labels
A group with nothing under it keeps its chevron but does not toggle. No dead disclosures.
Offerings sold separately
Their own top-level row, never a slot inside another category — a top-level row is the only one the one-open rule can never hide. Off-plan it still shows, with a pill when opened and a dot on the tile when crunched. What is still open is where in the list that row sits, and how hard it argues for itself: see the switcher above.
Never grey out an upsell
The tile keeps full colour. Greying it reads "not for you", which is the opposite of the job.
Highlight where it will be seen
The panel is crunched by default, so any emphasis living in the label row is emphasis almost nobody sees. The dot is on the tile for that reason.
Motion is periodic, not constant
The pill's sheen crosses once every 3.4s with a long hold, and the Context tile's gradient spins once every 6s, quickening to 1.4s on hover. Continuous, fast motion in a nav panel nags; these are the two exceptions, both dropped under reduced motion — and the Context tile's is the one that responds to the cursor, since a hover there is a hover on the thing being sold.
Preview on a dwell
300ms to open, 240ms to close. Nobody clicks a thing they have not been sold; the offer should arrive while the eye is already on the row. The close is slow enough to cross into the preview and reach its buttons, and the panel is held open while it is up.

The preview film

What plays inside the offer, at full size. It is not a video: it is the design system's own tokens animated with GSAP, so it re-themes with the product, costs a few KB where a screen capture costs megabytes, and cannot drift from a component the way a recording does. Scrub it — the beats are listed underneath.

1 · Gather
Twelve artefacts arrive — the six kinds the product is built on, and an example of each under it — from beyond whichever edge each one lands nearest, turning to face the viewer as they come. Twelve rather than six because the field has to look like a company's context and not like six category words.
2 · Combine
They converge on one point and become one bundle. This is the beat the product actually is: not six things wired to an assistant one at a time, but everything a company knows, handed over once. Six separate hand-offs would be six integrations, which is the thing Context Studio exists not to be.
3 · Handed over
One trip, one landing. The tile takes the hit, a ring goes out, the aura blooms into a different shape — the only thing on screen that is visibly not the same afterwards — the caption turns over from answers from what it was trained on to answers from your context, and six dots fill in underneath, one per kind.
4 · Ask, and answer from it
A question types in, the assistant thinks for a beat, and the answer arrives citing what it read — by name, in the colours those artefacts arrived in. It is the only place they come back, so they come back nameable.
Where it plays
Drawn once at 480×270 and scaled to its mount, so this stage and the 288px box in the offer run the same film rather than two that can disagree. Off-screen it is paused; in the offer it starts from the top each time the panel opens.
Reduced motion
Gets the last frame instead of the film: artefacts in, assistant bound, answer on screen. The whole story, held still — not a blank box.

Open questions

Decisions I made without a source, or left alone on purpose. Settle these first — they are the things most likely to change what you build.

Where Context Studio sits
Four candidates are live above. A keeps it in category order between Build and Library — closest to the work it feeds, at the price of reading as one more category. B puts it below every category under a rule, which says plainly that it is not one of them, and keeps it the last thing in the list wherever the list ends. C drops that same row to the foot of the panel, furthest from the categories and in one fixed place however many are open. D sits where B does but drops the rule for a box and a line of copy, which is the only one of the four that says what Context Studio is without a hover. It is also the only one that breaks the panel's rhythm, and the line is dead weight once someone knows the product. Pick one and the rest come out; it is one attribute either way.
What the film says
The six kinds are the ones in the brief. Everything else is invented: the examples under them (Snowflake, Jira · Confluence, Discount policy), the question, the answer and what it cites. All of it is a stand-in and wants product sign-off before this goes near a customer — invented product detail is the fastest way for a preview to say something untrue. It comes off one table, so replacing a name changes the field, the tally and the citation together rather than one of the three.
The film starts on every open
It restarts from the top each time the offer appears, which is right the first time and possibly a lot of motion the fifth. The alternatives are to resume where it stopped, or to play it once per session and hold the last frame after that.
Context, twice
Library still carries its own Context item from the Figma spec, alongside the new top-level Context Studio. If Context Studio replaces it, the Library row should go.
Re-opening when crunched
The crunched variant draws no control of its own. Hovering the panel is currently the whole affordance. There is no pin, so the panel cannot be held open.
Marketplace wash in dark
Figma names the pill's fill Gradient/blue but returns no value. Light is sampled from the component render; dark is derived. Replace if a dark variant gets drawn.
Groups with no children
Evaluate, Monitor and Resources are collapsed headers in every Figma variant. Their contents have not been designed.
Entitlement is a stub
A constant read off ?cs=owned. There is no real plan model, and only Context Studio is sold separately.

const railEl = document.querySelector('.rail');

/* The panel opens on hover and lays itself over the page, so nothing
   reflows behind it — the page's 68px gutter is constant. The delays keep
   a cursor crossing the rail on its way somewhere else from flashing it
   open; opening is quicker than closing, so an accidental overshoot on
   the way back in does not shut it. */
function setRailOpen(on) {
  railEl.classList.toggle('is-open', on);
}

let railPeekTimer = null;
function railPeek(on) {
  clearTimeout(railPeekTimer);
  railPeekTimer = setTimeout(() => {
    /* The preview sits outside the panel, so reaching for its buttons reads
       as leaving. Hold the panel open while it is up. */
    if (!on && $('upsell').classList.contains('is-open')) return;
    setRailOpen(on);
  }, on ? 120 : 220);
}

railEl.addEventListener('mouseenter', () => railPeek(true));
railEl.addEventListener('mouseleave', () => railPeek(false));
/* Hover is not the only way in — tabbing into the panel opens it too. */
railEl.addEventListener('focusin', () => { clearTimeout(railPeekTimer); setRailOpen(true); });
railEl.addEventListener('focusout', e => {
  if (!railEl.contains(e.relatedTarget)) railPeek(false);
});
/* Dismisses the peek without having to move the pointer off the panel. */
$('railCollapse').addEventListener('click', () => {
  clearTimeout(railPeekTimer);
  setRailOpen(false);
});
/* One category open at a time. Opening an item — or a group header —
   collapses the rest, so the panel only ever shows the section you are
   working in. That matters more at 68px, not less: crunched, the icons
   carry no grouping of their own, so a short list is the only thing that
   stays readable. Pass null to collapse everything. */
function railExposeOnly(group) {
  document.querySelectorAll('.rail-group[data-group]').forEach(g => {
    /* A group with nothing under it is a label, not a disclosure. */
    if (!g.querySelector('.rail-stack')) return;
    g.querySelector('.rail-ghead').setAttribute('aria-expanded', String(g === group));
  });
}

document.querySelectorAll('.rail-ghead').forEach(h => {
  h.addEventListener('click', () => {
    const group = h.closest('.rail-group');
    if (!group.querySelector('.rail-stack')) return;
    railExposeOnly(h.getAttribute('aria-expanded') === 'true' ? null : group);
  });
});

document.querySelectorAll('.rail-btn').forEach(b => {
  b.addEventListener('click', () => {
    document.querySelectorAll('.rail-btn.is-active').forEach(x => {
      x.classList.remove('is-active');
      x.removeAttribute('aria-current');
    });
    b.classList.add('is-active');
    b.setAttribute('aria-current', 'page');
    /* Home sits outside every category, so it collapses all of them. */
    railExposeOnly(b.closest('.rail-group'));
  });
});

/* Both Tiq bars sit beside the surface that owns them — the modal for the
   description writer, the detail panel for Ask Tiq — flipping to whichever
   side has room and clamping so the bar never leaves the viewport. `anchor`
   only sets where it starts vertically: the control the bar belongs to. */
function placeTiqBar(bar, owner, anchor) {
  if (!bar.classList.contains('is-open')) return;
  /* Docked, the bar is pinned by CSS; a stale inline left/top would fight it. */
  if (bar.classList.contains('is-docked')) { bar.style.left = bar.style.top = ''; return; }
  const gap = 12, edge = 12;
  const w = bar.offsetWidth, h = bar.offsetHeight;

  let left = owner.right + gap;
  if (left + w > window.innerWidth - edge) left = owner.left - w - gap;
  if (left < edge) left = Math.min(Math.max(edge, anchor.left), window.innerWidth - w - edge);

  let top = anchor.top;
  if (top + h > window.innerHeight - edge) top = window.innerHeight - edge - h;
  if (top < edge) top = edge;

  bar.style.left = `${Math.round(left)}px`;
  bar.style.top = `${Math.round(top)}px`;
}

/* Runs the gradient sweep across a bar's placeholder, once per bar for
   the life of the page — see .tb-ghost. Typing cuts it short, since a
   flourish that talks over the user is just in the way. */
const tiqShimmered = new Set();
function shimmerOnce(key, rowSel, ghostId, inputId) {
  if (tiqShimmered.has(key) || reducedMotion()) return;
  tiqShimmered.add(key);
  const row = document.querySelector(rowSel), ghost = $(ghostId), input = $(inputId);
  ghost.textContent = input.placeholder;
  row.classList.add('is-shimmer');
  const stop = () => row.classList.remove('is-shimmer');
  ghost.addEventListener('animationend', stop, { once: true });
  input.addEventListener('input', stop, { once: true });
}
