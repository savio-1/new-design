If you only ship one

The section answers “which libraries are we actually getting leverage from?” — one measure, five named things. That is a ranking question, so a sorted bar or lollipop reads fastest, and sorting is the part today's equal-track version is missing more than any chart type.

If the section should also carry how big each library is — Skills at 240 and Models at 18 are not comparable bets — the bubble or the stacked absolute bar earn their extra ink. The donut and treemap answer a question nobody asked here: what share of all reuse each type holds.

Why most of these are one colour

Reuse rate is a single measure, so a single hue is correct and the row label carries the name; colour per type is spent only where colour is the identity encoding — the donut, treemap, waffle and gauges.

Those four use a five-hue set computed against this page's card surface rather than picked by eye. The library's own icon hues fail outright as a chart palette: cyan, indigo, purple and blue sit at deutan ΔE 1.7 apart, invisible as a distinction. The set here holds ΔE 13.7 in light and 6.4 in dark, and every mark that uses it is also directly labelled.
