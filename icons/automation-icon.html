Cogentiq · Gradient icon set · Automation

The glyph carries the light

Three ways of setting the Automation glyph so that the icon itself glows in gradient, on a near-black rounded tile. The tile never changes between modes: it is the same asset on a cream page and on a deep ink page, so contrast holds in both.

Variation AGlow

The glyph at rest, centred. A single gradient runs Primary Indigo to Lavender Mist to Cream to Blossom along the diagonal, and two blurred copies underneath give it a soft halo in the same colours.

Variation BBleed

The glyph blown up six times and tilted, so the nodes run off the tile and the corner radius crops them. The gradient adds Ember at the top so the cut edges catch a warm tip. Best for feature tiles and marketing surfaces; it is still legible at 24 px because the form stays bold.

Light mode
Dark mode

Variation CPrism

A chromatic rim rather than a gradient along the path: five strokes of decreasing weight, Primary Indigo on the outside, then Blossom, Petal, and a Cream core. Each layer is blurred a little less than the one beneath it, which reads as light refracting off the edge of the form.

Recipe

Every colour is a Cogentiq token. All three variations share one glyph, one tile and one ground, and differ only in how the light is applied.

Tile
96 × 96 grid, corner radius 26. The ground is Deep Ink pushed almost to black along the diagonal, so the glyph is the only bright thing on the tile. A 1 px white hairline at 14% keeps the edge on dark pages.
Glyph
The Figma outline icon redrawn as strokes only: connectors with round caps and joins, nodes as round-capped dots. Because everything is a stroke, each glow or rim layer is the same geometry at a different weight, so the layers register perfectly at every size.
Glow
Gaussian blur on duplicate layers, never on the core stroke. The core stays crisp so the icon survives at 24 px.
Modes
No theme switch inside the asset. Only the page around the tile changes.
