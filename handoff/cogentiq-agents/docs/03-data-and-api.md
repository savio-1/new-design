# Data shapes and the API this screen needs

`js/01-data.js` holds four collections as literals. Replace them with
API responses and nothing downstream changes — every renderer reads
these shapes and nothing else.

The endpoints below are **proposed, not built**. Nothing in the
prototype calls a server; they are written down so the front end and the
API can be agreed before either is written.

---

## Collections

### Agent

The thing the page lists and the drawer describes.

```js
{
  name: 'Country Rate Checker',
  type: 'agent' | 'orchestrator' | 'remote',
  state: 'running' | 'idle' | 'review' | 'failing' | 'draft',
  desc: 'Checks the rates we quote in each country…',
  by: 'Priya Nair',                 // owner, drives "Created by"
  tags: ['pricing', 'sales'],
  updated: '2 days ago',
  runs: 412,                        // last 30 days
  problem: 'Model unreachable.',    // optional, drives NEEDS ATTENTION

  // workspace agents
  model: 'GPT-4o mini',
  parent: 'Spare Parts Stock Planner',   // optional, the orchestrator above it
  tools:  ['Price list lookup'],         // names, not counts
  skills: ['Compare rate to list', 'Explain a variance'],
  guards: ['Block quotes outside policy'],

  // everything, workspace and remote
  usedBy: [{ name: 'Quarterly price review', kind: 'automation' | 'assistant' }],

  // remote agents only
  conn: 'a2a' | 'direct' | 'rest',
  endpoint: 'agents.acmebank.com/a2a',   // host, no scheme
  server: 'Acme Bank A2A',               // server name, or the integration name for `direct`
  auth: 'Bearer token',                  // the label, already resolved
  cards: ['Fraud Signals'],              // exactly one, today
  agentSkills: ['fraud.score', 'fraud.explain'],

  // `direct` only — the mapped call
  reqMethod: 'POST', reqPath: '/v1/triage',
  msgField: '$.query', respField: '$.answer', ctxField: '$.session'
}
```

The card chips count `tools`, `skills` and `guards`; the drawer names
them. One source, so they cannot disagree — do not send both a count and
a list.

A marketplace agent is the same shape plus `installs: 1240`, and is
served from a separate collection.

### A2A server

Publishes several cards.

```js
{
  id: 's1',
  name: 'Acme Bank A2A',
  url: 'agents.acmebank.com/a2a',
  updated: '4 days ago',
  cards: [{
    name: 'Fraud Signals',
    desc: 'Scores a payment for fraud risk.',
    skills: ['fraud.score', 'fraud.explain'],
    auth: 'API key',
    path: '/.well-known/agents/fraud-signals.json'
  }]
}
```

### Integration

One agent card: where it is, how to authenticate, how to call it.

```js
{
  id: 'i1',
  name: 'Acme Claims Agent',
  url: 'https://agents.acme.internal:8443',
  desc: 'Assess a claim and assign a severity band.',
  auth: 'Bearer token',
  timeout: 60,
  skills: ['claims.triage'],
  method: 'POST', path: '/v1/triage',
  msg: '$.query', resp: '$.answer'
}
```

Credentials are **not** in this shape. In the prototype they sit in
memory on the object; in the product they belong in the secret store,
referenced by id.

### Spec operation

Read off an uploaded OpenAPI document, one per operation.

```js
{ op: 'GET /forecast/{city}', skill: 'weather.forecast', desc: 'Ten-day forecast for a named city.' }
```

## The Agent Card

Every route ends holding one, and it is what gets stored. `cardJSON()`
builds it; the review step shows exactly what will be saved.

```jsonc
{
  "name": "Fraud Signals",
  "description": "Scores a payment for fraud risk.",
  "version": "1.0.0",
  "url": "https://agents.acmebank.com/a2a/.well-known/agents/fraud-signals",
  "provider": { "organization": "Acme Bank A2A" },
  "capabilities": {
    "streaming": true,
    "pushNotifications": false,
    "stateTransitionHistory": true
  },
  "authentication": { "schemes": ["API key"] },
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["text/plain"],
  "skills": [
    { "id": "fraud.score", "name": "Score", "description": "…", "tags": ["fraud", "score"] }
  ]
}
```

Per route:

- **a2a** — fetched from the server, used as-is; only `authentication.schemes`
  reflects what the user chose.
- **direct** — built from the integration, and carries one extra block
  so the adapter can rebuild the call from the card alone:

  ```jsonc
  "adapter": {
    "request":  { "method": "POST", "path": "/v1/triage", "message": "$.query" },
    "response": { "text": "$.answer" },
    "timeoutSeconds": 60
  }
  ```

- **rest** — generated by the managed adapter, `provider.organization`
  is `Cogentiq Managed A2A`, one skill per operation.

## Endpoints the screen implies

| Screen moment | Method + path | Returns |
| --- | --- | --- |
| Page load, In workspace | `GET /agents?scope=workspace` | `Agent[]` |
| Marketplace tab | `GET /agents?scope=marketplace` | `Agent[]` with `installs` |
| Drawer open | — | nothing extra; the list carries it all |
| Integration dropdown | `GET /integrations` | `Integration[]` |
| Create integration | `POST /integrations` | the created `Integration` |
| Server dropdown | `GET /a2a/servers` | `Server[]` |
| Register a server | `POST /a2a/servers` → `GET /a2a/servers/{id}/cards` | discovered `Card[]` |
| Card chosen + credentials entered | `GET /a2a/servers/{id}/cards/{card}` | the Agent Card JSON, fetched with those credentials |
| Spec uploaded | `POST /specs:validate` (multipart) | `{ ok, version, operations: Op[], url, auth }` or `{ ok: false, error }` |
| Register agent | `POST /agents` | the created `Agent`, `state: 'review'` |

Notes for whoever writes these:

- **Validation is a round trip, not a guess.** The upload step blocks
  Continue until the server answers, and the UI already has a `checking`
  state for the wait.
- **The card fetch is credentialed.** Route B only shows the card after
  the credentials are entered, because fetching it is the first proof
  they work. A 401 there is a real, expected state — design it as an
  inline error on the credential field, not a toast.
- **Registration returns the agent**, and the UI lands on it with the
  filters reset to In workspace → Remote. Return the full record so no
  second fetch is needed.
- **Secrets never come back.** Post them once; return a reference. The
  drawer shows the auth *method*, never the value.
