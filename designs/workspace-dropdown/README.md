# Workspace switcher dropdown — options

Four design options for the top-right workspace dropdown, each showing the
workspace name alongside its automation / assistant / agent counts.

- `gen.mjs` — generates the four artboards (`Main.dc.html` = Option A,
  `OptionB/C/D.dc.html`) and `canvas.json` from one sample data set.
  Run `node gen.mjs` after editing.
- `workspace-switcher.html` — the assembled design canvas (generated, do not hand-edit).

Counts in the mockups are sample values, not real workspace data.
